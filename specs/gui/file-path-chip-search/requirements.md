# 文件路径 Chip 搜索与候选选择 — 需求文档

> 最后更新: 2026-08-18 | 状态: building

## 背景

文件路径 chip 目前会在出现时执行预检，多个 chip 同时出现时可能造成主进程卡顿；同名文件存在于不同目录时，也缺少让用户逐个搜索和选择目标文件的交互。

## 需求

### 1.1 延迟搜索

As a user, I want 文件路径 chip 出现时不自动搜索文件系统 so that 大量 chip 同时出现时不会造成界面卡顿。

- chip 首次出现只完成路径识别和基础展示。
- 搜索仅由用户主动操作触发。
- 搜索范围仅限当前会话相关路径：会话文件、工作区文件、当前会话附加文件夹。
- 不扫描无关工作区、全局用户目录或其他会话目录。

### 1.2 首次点击 chip

As a user, I want 首次点击尚未搜索过的 chip 时执行一次简单搜索并打开结果 so that 普通文件路径仍然可以一次点击完成预览。

- 若该 chip 尚未搜索过，左键点击执行一次简单搜索。
- 简单搜索找到一个候选文件后立即停止，并打开该文件预览。
- 搜索不到文件时保留 chip，并显示明确的未找到状态。
- 若该 chip 已经有当前选中的候选文件，左键点击直接打开当前选中候选，不重复触发首次搜索逻辑。

### 1.3 搜索按钮与同名候选

As a user, I want 通过 chip 后的搜索按钮逐次寻找同名文件 so that 我可以处理多个目录中的同名文件而不被系统擅自选错。

- 每个 chip 后显示搜索按钮；默认可点击。
- 轻点搜索按钮执行一次简单搜索，找到一个此前未返回的同名文件后停止。
- 重复轻点可继续寻找下一个未返回的同名文件。
- 已返回的候选路径不得重复返回。
- 每个候选保存完整真实路径，并可成为当前预览目标。
- 搜索结果按当前会话相关路径范围过滤。

### 1.4 深度搜索

As a user, I want 长按搜索按钮执行深度搜索 so that 较深目录中的同名文件也能被找到。

- 长按搜索按钮触发深度搜索。
- 长按触发时长为手动压缩上下文按钮长按时长的一半。
- 深度搜索仍只限当前会话文件、工作区文件和附加文件夹。
- 深度搜索每次仍以未返回的候选为目标，不重复返回已知路径。

### 1.5 后台搜索与取消

As a user, I want 搜索在后台执行且可以中止 so that 搜索期间界面保持响应。

- 简单搜索和深度搜索均不得同步阻塞 Electron 主进程或 renderer。
- 搜索进行时，搜索按钮变为可点击的转圈图标。
- 点击转圈图标立即取消当前搜索。
- 取消后已找到的候选保留，未完成的候选不继续写入结果。
- 搜索完成、取消或失败后，转圈图标恢复为可点击的搜索图标。
- 搜索过程中同一 chip 不得启动重复搜索任务。

### 1.6 候选路径选择

As a user, I want 通过搜索按钮右键查看并选择候选完整路径 so that 我可以明确决定 chip 打开哪个同名文件。

- 右键搜索按钮弹出候选路径菜单。
- 菜单展示当前已经搜索到的候选真实完整路径。
- 用户选择某条路径后，该路径成为当前 chip 的选中预览目标。
- 后续左键点击 chip 打开当前选中的候选文件。
- 没有候选时显示空结果状态，不执行无意义的选择操作。

### 1.7 Chip 显示切换

As a user, I want 右键 chip 本体切换显示信息密度 so that 我可以在简洁显示和路径确认之间切换。

- 默认显示单文件名 chip，例如 `settings.json`。
- 右键 chip 本体切换为完整路径 chip，例如 `C:\\project\\src\\settings.json`。
- 再次右键切回单文件名 chip。
- 两种状态均保持 chip 样式、文件图标、颜色、点击预览和搜索按钮。
- 不显示普通无边框原文，也不显示 Markdown 反引号。

### 1.8 附加文件夹操作入口

As a user, I want 附加文件夹和其他文件夹使用一致的更多操作入口 so that 我不会把关闭/取消附加和删除文件混淆。

- 附加文件夹 tab 后不再直接显示叉按钮。
- 附加文件夹统一显示更多操作按钮。
- 更多操作菜单中提供“取消附加/移除附加文件夹”操作。
- 用该操作替换当前二级菜单中的删除按钮。
- 取消附加只移除当前会话的附加关系，不删除磁盘上的文件夹。

## 非功能需求

- 搜索结果必须在授权范围内，不能因候选搜索扩大文件访问权限。
- 搜索必须有明确的生命周期：可启动、进行中、完成、取消、失败。
- 搜索结果和当前选中路径应缓存，避免重复扫描。
- 取消搜索后不得继续更新 UI 或覆盖用户已选择的候选。
- 兼容 Windows `/`、`\\`、混合分隔符、中文路径和带空格文件名。
