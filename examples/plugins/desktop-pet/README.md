# Profer 桌宠

这是开发版插件平台的一个轻量桌宠示例。它使用 `pluginStorage` 保存昵称、心情、能量和饱腹状态，不需要网络、模型或系统权限。

## 安装

1. 启动 Profer 开发版。
2. 打开「设置 → 插件」入口。
3. 选择「安装目录」，选中当前目录：
   `/Users/mac/profer/profer-main/examples/plugins/desktop-pet`
4. 查看并授权 `pluginStorage`。
5. 在插件设置或左侧栏打开「桌宠」。

修改插件源码后，需要在插件设置中重新安装并选择替换；只改源目录不会自动刷新已安装副本。

## 当前范围

桌宠目前以 Profer 左侧栏页面运行。当前插件平台尚未提供独立悬浮桌面窗口或 OS 系统能力，因此这个示例没有伪造系统级桌宠行为。后续宿主提供窗口能力后，可以在不改动状态与交互层的前提下复用本插件。
