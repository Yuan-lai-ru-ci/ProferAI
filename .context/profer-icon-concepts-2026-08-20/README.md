# Profer 图标概念稿（2026-08-20）

本目录是设计探索稿，不替换生产图标资产。

## 已确认的设计约束

- 不使用字母 P 或文字构形
- 柔和智能，而非冷硬科技
- 圆润几何的软方体
- 两片主体前后叠合
- 底部相拥、顶部向右上开放
- 黑白灰、微立体，不使用彩色渐变
- 同一核心轮廓应支持透明底、黑底白标、白底黑标

## 三个方向

- `concept-steady.svg`：稳重版。重心低，层次最克制，适合作为主候选。
- `concept-space.svg`：空间版。光隙更宽，强调工作区和能力层次。
- `concept-motion.svg`：动势版。斜向更明显，强调响应、成长和向前展开。

预览：打开同目录下的 `index.html` 查看第一轮；打开 `round-2.html` 查看流动丝带与弧月形体第二轮。两页都包含黑白双版本和 64/32/16px 缩小效果。

## 第二轮方向

- `concept-ribbon.svg`：流动丝带。连续、柔软、有内腔，重点是形成独立的运动节奏。
- `concept-crescent.svg`：弧月形体。单一厚实的开放形体，更克制、更安静，像智能入口。
