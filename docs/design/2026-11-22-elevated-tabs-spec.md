# Tab 浮起表面与防误触规范

生效决策：2026-11-22。由云朵舞者顶栏建议推广为共用策略；最终决定不做浏览器式腰部或底部外扩圆弧。

## 表面层级

- 选中标签通过浮起表面和柔和阴影表达，不使用厚重深色填充与反白文字。
- 表面取 `--tab-active-surface`，默认跟随 `--raised-surface`；阴影取 `--shadow-tab`。云朵舞者为白色，深色和自定义皮肤按表面 token 适配，不强制白底。
- 顶栏标签保留四角完整 8px 圆角，草稿固定图标入口保留 10px 圆角。无腰部、无外扩脚部。
- 未选中标签背景透明、无常规描边；hover 显示轻微表面反馈。键盘 focus-visible 保留可辨识焦点。
- 会话、文件预览、浏览器、教程、插件和组合标签共用顶栏表面；右侧文件视图 Tab 共用相同颜色与阴影，不再按经典/现代界面分叉。设置等分段选择器保留既有几何，不机械改成文档标签。

## 防误触

- 标签不放常驻铅笔按钮；单击切换，支持重命名的会话双击标题进入行内编辑，右键菜单保留重命名入口。
- 双击图标、空白、工作区徽标或快速键盘激活不触发重命名；拖拽与指针取消打断双击序列。
- Enter 保存、Escape 取消、失焦保存；输入法组合阶段不提交。连续保存事件只提交一次，失败保留草稿供重试。
- 不具备重命名能力的标签不显示双击提示，不把文件/网页标题重命名偷换成文件改名或网页修改。

## 状态

- 未选中运行标签使用微型呼吸点，仅 hover 或 focus-within 可见，保留占位避免标题跳动；组合标签沿用相同规则。
- 激活运行会话保留原有运行状态环。等待确认、已完成等提醒仍保持可见，不随着运行点一起隐藏。
- 系统减少动态效果时停止呼吸和状态环动画。

## 验收

- 浅色/深色实际组件渲染；运行点隐藏与聚焦显现；完整圆角且无腰部。
- 标题双击、非标题点击、拖拽、键盘激活、保存/取消/失败重试回归。
- 相关标签测试、Electron typecheck 与 diff 检查；原生窗口拖拽/指针捕获需在 Electron 实机另验。
