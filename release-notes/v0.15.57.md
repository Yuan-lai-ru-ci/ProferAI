# Profer v0.15.57

## 修复

- 修复「全局元 Skill」库在升级后，部分 Skill 卡片错误显示“暂无描述”的问题。原因是历史 Skill 文件的 Windows 换行格式与旧版元数据解析不兼容；现在解析器会兼容 LF/CRLF，内置 Skill 资源也统一使用 LF。
- 修复 Profer 品牌迁移后仍保留旧 Proma 元 Skill 内容的问题。升级时会识别历史内置 Skill 的完整目录指纹，并安全升级到当前 Profer 版本。

## 数据保护

- 只有完整匹配 Profer/Proma 历史内置版本的元 Skill 会自动迁移。
- 用户自行编辑过正文、添加过脚本或参考文件的 Skill 不会被覆盖，仍保留原有内容。

## 升级提示

- 升级后重新打开「Agent 技能 → 元 Skill」或点击“刷新”即可看到恢复后的描述。
