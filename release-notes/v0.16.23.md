# Profer v0.16.23

## 新增

- **项目会话自包含**：项目工作区的会话消息、任务图、Harness 与 Pi transcript 落到项目内 `.profer/sessions/<id>/`，大载荷进 `.profer/blobs`。整个项目文件夹拷到另一台电脑后打开即可恢复列表与对话，`index.json` 缺失时也能按 `session.json` 对账重建；备份导出可只选会话，不带配置。
- **Agent 会话回退与文件恢复**：新增「预览 → 执行 → 撤销」全链路，受控 write/edit 记录同一次工具调用的 before/after 证据，回退对话时按工作区或项目覆盖度恢复文件；Claude 与 Pi 两端都会上报证据，远程与旧版 Pocket 不带模式时只回退对话。
- **用户画像与全局记忆下沉**：新增 `@profer/user-memory`，CLI 与主进程共用同一份画像读写实现，并新增 `profer profile show|get|set|context|search`；`profer profile context` 可直接作为 system prompt 片段，Agent 侧注入全局记忆索引。
- **渠道自配不再分级**：取消商业模式下对渠道新建、修改、删除与登录的会员拦截，自配对所有账号开放；字段与 IPC 保留以兼容旧界面与服务端。
- **「我的画像」全屏视图**：首屏直接改名字、头像与常用字段，二级页管理全局记忆文件；顶部 rail 新增入口，跨工作区用量热力图合并展示。
- **会话删除快捷键**：macOS 默认 `Cmd+Backspace`，Windows / Linux 默认 `Ctrl+Delete`。
- **聊天图片复制**：图片消息支持右键复制到剪贴板。

## 优化

- **全屏视图统一骨架**：规划中心、Agent 技能、Agent 记忆、我的画像共用一套 `ViewHeader / ViewBody / ViewToolbar`，页头与主操作位不再各写一遍。
- **顶栏与迷你地图**：拖拽层按标签实测几何计算，横向滚出视口的标签不再越界压住侧栏拖拽条；迷你地图改成 Segmented Navigation 旋转形态，颜色全部走主题 token，皮肤无需额外配置。
- **队列自动发送语义收敛**：去掉会话级「自动发送」开关，左键入队即发送意图，队列始终自动发；唯一暂停来源是「停止」，下一次显式发送或空闲直发时恢复。
- **委派阻塞判定下沉**：阻塞事件与唤醒判定移入 `@profer/agent-runtime`，`wait_for_delegations` 遇到阻塞会提前返回 `blocked`。

## 修复

- **项目会话消息写错目录**：异步写盘线程没有会话布局注册表，会把 project 会话的消息写回全局 `agent-sessions`，导致项目文件夹换机器后最新对话全部丢失；现由主进程按会话布局解析路径随批次下发。
- **会话迁移安全**：迁移前预检会话树、目标根与同 ID 冲突；委派子树有运行中或分叉即拒绝；父会话失败回滚已迁移的子会话；目标已有同 ID 非空会话时整条停下上报冲突，不覆盖任何一边。
- **项目会话路径校验**：会话 ID 白名单、项目内越界与符号链接逃逸检查；跨项目同 ID 冲突不再按 `updatedAt` 抢占，双方数据都保留并记录诊断。
- **重新绑定项目不刷新列表**：收到工作区变更广播时补拉会话列表，解绑再绑定同一目录后历史会话立即出现，不用再发一条消息触发。
- **压缩锁卡住输入框**：只有手动 `/compact` 才置 `compactInFlight`，自动压缩结束立即恢复运行指示；新增 `compact_failed`，压缩失败、取消或跳过时同样释放锁。
- **Windows 覆盖安装**：安装与卸载前先探测进程，按 `--quit` 优雅退出 → `taskkill /F /T` → UAC 提权重杀逐级处理；文件关联不再指定 icon，安装器也不再重写被 Shell 持有句柄的 `resources/icon.ico`。
- **布局改造回归**：managed 工作区恢复历史 mkdir 行为，Pi Harness 与任务图首次写入不再 ENOENT；孤儿清理区分可解析与不可解析文件，避免误删未知 `.jsonl`。
- **Escape 关闭对话框**：AlertDialog 允许 Escape 直接关闭。

## 升级提示

- **项目会话会就地迁移**：升级后首次打开项目，后台把存量会话消息、任务图、Harness 与 transcript 搬进项目目录，运行中的会话跳过、可重复执行；迁移前会备份全局索引。`profer.json` 新增 `sessionLayout=2`，新项目直接按新布局创建。
- **项目文件夹可整体拷走**：`.profer/` 已在默认忽略规则内，不要提交到项目仓库；拷到另一台电脑后重新打开项目即可恢复会话。
- **渠道不再区分会员等级**：此前被托管模式隐藏的自配入口对所有账号开放。
