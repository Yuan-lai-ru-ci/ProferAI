# Profer v0.16.16

## 新增

- **会话悬浮预览**：鼠标悬停在侧栏会话上弹出该会话的预览面板，面板可移入保持、可主动关闭，全局搜索结果同样生效；侧栏当前会话行不预览，菜单打开时也不预览。新增「界面交互 → 会话悬浮预览」开关，默认开启。
- **悬停意图判定**：按位移容差判断是否真的停在某一行，鼠标扫过大列表时不再每一行都起计时，手抖不再打断预览。

## 优化

- **流式渲染性能**：增量按对话切片订阅，分屏时另一个 pane 的增量不再唤醒整棵树；流式会话 id 集合内容不变时复用引用，侧栏呼吸点、标签栏与移动端标签不再每个 token 重渲染；已定稿的 Markdown 块按 source / components / 插件记忆化，长回答流式时不再每帧重解析全部块。
- **顶栏**：操作区改为 34px 浮起胶囊（28px 按钮 + 内边距 + 描边），不再贴窗口上沿；只剩一个控件时退化为裸图标。常驻的「界面引导」按钮移出顶栏，入口留在设置页与教程横幅。新消息圆点改小并加环，不再压在图标上。
- **侧栏项目折叠**：折叠策略收敛到纯函数——置顶与活跃会话常显且不占预览上限，其余按更新时间倒序补足，去掉「最近 3 天」窗口叠加，旧项目不再只剩一行「显示更多」。项目标题单击即切换（折叠只走 chevron，删掉 500ms 双击延迟），有色标会话统一中性淡底，色相只留在左侧竖条与状态图标。「显示更多」标注剩余条数。
- **模型选择器**：Agent 选择器名称宽度 130→180px，Chat 选择器 220→200px。

## 修复

- **Windows 平滑滚动默认关闭**：自绘弹簧要挂非 passive 的 wheel 监听并 preventDefault，整页失去合成器滚动快速路径，流式输出时主线程被渲染占满，接管反而比原生更卡。现在默认交回 Chromium 合成器线程，需要 macOS 式惯性的用户可在设置里手动开启，设置文案写明这个代价。
- **加载更早消息**：prepend 期间按 scrollHeight 增量保持视口，不再依赖会随过程组重建消失的块锚点；触顶分页改为只在用户真正滚离顶部（top > 40）后重新武装，不再一次拉完整段历史。「加载更早消息」补 ArrowUp 图标，保留手动入口。
- **文件变更 chip 误报**：原先从 tool_use 的命令文本推断写入路径，把 `curl -w "%{http_code}"`、`sub_filter "</head>"`、`created_at >= ...` 里的片段当成文件，产生 `<meta>` / `head>` / `=` / `0` 这类假 chip。改为只报确定发生过的写入：Pi write/edit 落盘后上报路径（含工作区外）；Bash 三个执行分支统一包一层执行前后目录快照，diff 出新增/修改，覆盖 `sed -i`、heredoc、`python3 -c` 等不经过受控 operations 的写入；主进程按 toolCallId 收集并随 JSONL 落盘，历史会话回放同样可读。快照只读 mtime/size，跳过 `node_modules`、`.git`，超出 2 万文件 / 深度 8 / 800ms 预算时放弃本轮检测，不影响命令本身。
- **微信 Bridge 状态**：此前只在「微信」设置页挂载时加载并订阅，没进过该页时侧栏状态点恒为未连接、离开页面后也不再更新。现在与飞书、钉钉对齐，提到根组件常驻订阅。
- **钉钉 Bot 配置**：移除 Bot 级默认渠道与默认模型，只保留默认工作区——渠道与模型已由会话/预设决定，Bot 级默认值会和移动端继承逻辑打架；同步收敛设置页文案与集成配置用例断言。

## 测试

- 飞书补齐命令级回归基线（卡片/文本结果、绑定落盘、配置写回），不依赖飞书 SDK；`FeishuChatBinding` 注释改为实际持久化路径。

## 升级提示

- 本版起 Windows 平滑滚动默认关闭。恢复旧手感：设置 → 界面交互 → 平滑滚动开。
