# v0.17.1-beta.2

## 本版范围

- 本机 Core 默认运行，移除启用开关；关闭设备共享不影响本机执行。保留显式 legacy 启动兜底，不在故障后自动切核或重放任务。
- 新增跨设备连接：一次性邀请、持久 TLS 身份、UDP 发现、地址更新与离线保留目标。
- Core 与旧桌面共用执行锁，旧安装升级后自动接续会话与工作区。
- 修复预览命名空间重复与共享快照抢占宿主绑定。

- 独立 Core 管理商业账号、续期与官方模型目录，修复过期账号恢复遇临时服务错误后缺少重试。
- 收敛设置导航、Tab、共享滚动与空状态；新增 Skill 路由卡缺失提醒。

## 更新策略

- 预发布版仅支持手动安装，不自动检查、下载或安装正式通道更新。
