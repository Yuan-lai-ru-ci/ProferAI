# Profer 0.17.1-beta.1

## Beta 范围

- 商业版测试候选，目标为 Windows x64、macOS arm64、Linux x64 桌面，以及独立 Linux Headless Core。平台构建、签名和实机验收状态以随包验证清单为准。
- Linux Headless 不依赖 Electron、Renderer 或图形桌面；桌面版与 Headless 共用 Core 实现和协议。

## 更新策略

- 预发布版仅支持手动安装，不自动检查、下载或安装正式通道更新，也不回退到开源版更新源。

## 内核试用

- 桌面包携带独立 Core 运行目录；本机 Core 保持显式试用，不默认迁移既有用户数据。
- Core 官方托管渠道与部分桌面宿主能力尚未对等，具体支持范围见随包说明；不能把自带 API Key 验证当作商业账号链路验证。
- 首次试用请使用隔离配置、工作区和 userData，不覆盖日常安装与配置。
