# Profer v0.16.21

## 新增

- **模型提议建立 Goal**：长任务里模型可以主动建议建立一个 Goal，卡片给出目标、理由与验收标准，点「建立 Goal」才创建，不打断当前这一轮。策略可选「先问我 / 直接建立 / 关闭」，默认每次确认。
- **Goal 空闲自检**：Goal 一轮结束后如果你没有发消息，可按设定间隔自动继续，连续达到上限后停下等你；默认关闭，发消息会清零计数并立即续跑。
- **Goal 总览**：规划中心新增 Goal 分区，可跳转查看跨会话的目标；会话内 `/goal status` 提供结构化面板。
- **文件拖拽引用**：会话文件、工作区文件与变更列表可直接拖入输入框，生成 @ 引用。

## 优化

- **Mistral 推理档位**：官方模型按模型维度声明推理能力，已开通推理的账号能用上思考档位；同渠道的第三方模型 id 保持禁用。
- **Goal 教程**：教程补齐 `/goal` 命令族、契约行、状态栏、终态通知与受阻待办。

## 修复

- **图表闪空**：会话内 ECharts 改用 canvas 渲染，鼠标扫过柱状图时柱子不再变空白。
