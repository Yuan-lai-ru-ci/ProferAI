# Proma v0.16.0 更新

## 新功能

- **待办与日历工作区** — 可以在 Proma 中管理本地待办、日程、分组、标签和提醒，并在需要时让 Agent 直接协助处理。
- **日历视图增强** — 周视图支持更顺畅地切换周次，定时任务会按实际执行计划显示在周历和月历中，悬浮即可查看详情。
- **在对话中引用计划项** — 输入 `@` 时可搜索并引用待办和日历日程，让 Agent 结合具体事项提供帮助。
- **从待办启动 Agent** — 可以从待办直接发起 Agent 对话，让 Agent 帮你处理该事项。
- **计划窗口快捷键** — 新增快速打开计划窗口的快捷键，可从快捷键地图中查看。
- **快捷键地图** — 新增快捷键总览，方便查看和记忆常用操作。
- **设置页焕新** — 设置从弹窗调整为独立工作区，浏览和修改配置更清晰。
- **统一文件面板** — 项目文件和会话文件现在在同一处浏览；会话文件可移入项目，供其他会话继续使用。
- **会话悬浮预览** — 可以在设置中开启会话悬浮预览；同时取消 Agent 修改文件后文件树自动跳转，减少操作打断。
- **更清晰的模型与能力提示** — Pi 现在标为推荐内核，Claude 标示即将下线；更多模型可使用统一的推理强度设置，Claude Opus 5 支持 100 万上下文。
- **工具活动更易读** — Agent 读取 Skill 时会在工具活动中明确显示。

## Bug 修复

- **长对话更稳定** — Pi 会更早整理过长上下文，并在整理后继续执行任务、保留进度显示。
- **网络异常自动恢复** — 改善 Pi 对损坏流式响应和重试过程的处理，减少回答中断或卡住的情况。
- **运行中切换模型** — Agent 正在执行时也可以切换模型，切换后会正确生效。
- **命令与引用输入更可靠** — 改善 `/` 命令、文件路径和引用搜索的兼容性，避免输入被错误拦截。
- **协作会话状态同步** — 委派给子 Agent 的会话在创建、运行和结束时会正确更新界面状态，并沿用当前模型。
- **任务过程控制更顺畅** — Agent 生成草稿时即可停止；内核和推理强度的修改会在当前任务结束后生效，避免中途打断。
- **其他体验修复** — 修复 Codex 会话标题偶发冲突、PDF Skill 识别、引用内容后焦点跳转、固定会话数量限制、已完成待办仍计入数量、飞书新机器人会话同步、自动任务布局以及 Excel 单表预览行数不足等问题。
