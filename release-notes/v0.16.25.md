# Profer v0.16.25

## 新增

- **受管浏览器在系统浏览器打开**：面板工具栏与加载失败态新增入口，把当前页交给系统默认浏览器；地址由主进程按标签读取，支持 localhost 与局域网开发地址，空标签与本地预览不显示入口。
- **新会话居中布局**：空会话时欢迎语与输入框一起垂直居中，开始对话后恢复贴底输入；消息区仅隐藏不卸载，滚动位置与实时订阅保持存活。

## 优化

- **运行链加固**：停止语义区分「发停止信号」与「停止并排空」（`stop` / `stopAndWait`），共用有界 deadline；资源未退出前保留 owner，迟到 drain 后才释放。新增 run 结果快照与终态投影；旧 Goal 父停止会级联新链子会话，子会话独立存活。
- **工具门禁收紧**：本轮没有冻结策略快照时资源准备 fail-closed，不再按预填清单猜测权限；最终工具、Skill 与 MCP manifest 按同一份策略裁剪。
- **持久化回执**：落盘新增 accepted / saved / failed 回执与有界 ACK 重试，单会话失败隔离且后继不越过未知前序；`accepted` 不再被当作已保存。
- **契约门禁**：运行链契约测试（准入、最终工具策略、Skill/MCP manifest、结果快照）接入发布与 macOS 打包流程。
- **活跃热力图统一到画像页**：欢迎页不再展示工作区热力图与模式切换 Tab（模式由侧栏切换），画像页顶部改为跨工作区聚合的活跃卡片。

## 修复

- **保存失败时会话历史整段空窗**：落盘停在 pending/failed 时不再丢弃这一次读盘，历史照常加载；只有落盘可信时才清理实时副本，运行中打开无缓存会话也能看到旧消息。
- **旧链路保存失败不再提示**：不带 runId 的持久化 ACK 只触发失败提示，不改写本轮状态。
- **`propose_goal` 参数被上游拒绝**：参数改为合法的 typebox Object schema。此前直接写字面量对象，序列化后缺少 `type`/`properties`/`required`，严格校验的渠道（如 DeepSeek）会整轮 400。
- **切回刚结束的会话残留「运行中」**：60 秒终态回放不再覆盖本窗口已收敛的状态，不再需要刷新才能继续输入。
- **权限模式在权限端口与 provider 之间错位**：本轮 run facts 写入收敛后的策略值，权限端口依次参考本轮覆盖、冻结的策略快照与会话元数据；预设未声明权限的历史会话不再退化成每一步都要确认。
- **移动端发出的任务卡在等待批准**：`send_message` 透传合法的 `permissionMode`，历史会话也能靠本轮覆盖恢复无人值守语义；非法值不会进入 run。
- **macOS 输入法组合期间误触缩放**：交通灯缩放同步忽略已消费、输入法组合与自动重复按键。

## 升级提示

- 本版无数据迁移；升级后直接覆盖安装即可。
- 持久化回执与批次标记是进程内语义，不承诺断电或跨进程 exactly-once；durable outbox、fsync 与历史 JSONL 批量修复不在本版范围。
