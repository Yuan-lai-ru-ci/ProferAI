# Profer v0.16.25

## 新增

- **受管浏览器在系统浏览器打开**：面板工具栏与加载失败态新增入口，把当前页交给系统默认浏览器；地址由主进程按标签读取，支持 localhost 与局域网开发地址，空标签与本地预览不显示入口。
- **新会话居中布局**：空会话时欢迎语与输入框一起垂直居中，开始对话后恢复贴底输入；消息区仅隐藏不卸载，滚动位置与实时订阅保持存活。

## 优化

- **活跃热力图统一到画像页**：欢迎页不再展示工作区热力图与模式切换 Tab（模式由侧栏切换），画像页顶部改为跨工作区聚合的活跃卡片。

## 修复

- **`propose_goal` 参数被上游拒绝**：参数改为合法的 typebox Object schema。此前直接写字面量对象，序列化后缺少 `type`/`properties`/`required`，严格校验的渠道（如 DeepSeek）会整轮 400。
- **切回刚结束的会话残留「运行中」**：60 秒终态回放不再覆盖本窗口已收敛的状态，不再需要刷新才能继续输入。
- **权限模式在权限端口与 provider 之间错位**：本轮 run facts 写入收敛后的策略值，权限端口依次参考本轮覆盖、冻结的策略快照与会话元数据；预设未声明权限的历史会话不再退化成每一步都要确认。
- **移动端发出的任务卡在等待批准**：`send_message` 透传合法的 `permissionMode`，历史会话也能靠本轮覆盖恢复无人值守语义；非法值不会进入 run。
- **macOS 输入法组合期间误触缩放**：交通灯缩放同步忽略已消费、输入法组合与自动重复按键。

## 升级提示

- 本版无数据迁移；升级后直接覆盖安装即可。
