# Profer v0.16.15

## 新增

- **独立会话窗口**：Tab 可以拖出或右键「移到新窗口」，新窗口只渲染那一个会话，不复制侧栏和全局初始化；独立窗口按会话绑定 Agent 流，可以移回主窗口并恢复草稿。macOS 的 Window / Dock 菜单会动态列出所有独立窗口，支持恢复最小化窗口；Windows 侧适配自绘标题栏、最大化状态、菜单栏与多显示器几何。
- **引用体系重做**：引用改为输入框里的待发送列表，可累积、去重、拖拽排序，超 5 条自动滚动，发送时整组消费，失败自动回填；运行中发送不再排队，直接插入当前轮。发送后引用写成正文里的 `[n]` 标记和引用块，随消息持久化，点胶囊能跳回原消息，原文侧新增批注栏（竖条 + 编号，同行多条合并为 3·4）。
- **引用胶囊悬停预览**：悬停 750ms 弹出「来源细节 + Markdown 原文」，同一时刻只留一个浮层，滚动、缩放、ESC、失焦即收；贴视口边缘自动收窄或改右缘对齐，上方放不下翻到下方。
- **运行中消息队列与自动发送**：运行中追加的消息进队列，可编辑、删除、拖拽排序，轮结束后按开关自动发送队首；开关按会话持久化，手动停止会关掉自动发送但保留队列，发送失败按间隔节流重试。
- **「引用到输入框」右键菜单**：原生菜单新增该项，渲染进程上报选区是否位于可引用区域。

## 优化

- **推理能力矩阵与上下文窗口**：推理档位按模型家族拆分，新增 `reasoning-model-tag` 作为家族判定单一事实源；模型注册表补齐 GPT-6.1 Sol 等新模型，上下文窗口按家族推导，渠道表单按协议提示 Responses 端点。
- **适配器按端点协议选择**：`getAdapter` 传入实际 baseUrl，标题、插件、回顾等旁路请求与聊天走同一套协议判定。
- **Anthropic 端点与内核选择收口**：统一 Chat / Agent / Pi 的 URL 推导（`/v1/messages`、`/v1/models`），修复 `/anthropic` 等路径漂移；只勾 Claude 或只勾 Anthropic 协议的 Pi 时不再依赖空 baseUrl 才能测试、发现模型和创建渠道；IM Bot 跟随全局 `agentRuntime`，回退渠道时重新解析有效模型。
- **滚动条分平台统一**：首帧写入 `data-platform`，尺寸、命中区、常驻显隐按 macOS 与 Windows 分叉，弃用 `scrollbar-width: thin`；侧栏列表占位槽伸进留白，不再挤压行宽。
- **侧栏列表**：会话时间恢复常显（选中项与其余行保留灰度层级），置顶入口移到标题左侧留白，hover 不再让标题横向跳动；会话行改 28px 高 + 底边分隔线；子会话计数标记贴到行尾，标题占满剩余宽度。
- **远程连接**：移动端新建会话缺省继承桌面「上次使用」的渠道与模型，手机只发标题也能直接发消息；移动端切换模型同步写回全局默认。
- **文件预览**：预览标题栏最右补关闭按钮，与顶栏 Tab 的 ×、`Cmd+W` 走同一条关闭路径，分屏下会连带清理预览 Tab 元数据。
- **提示词侧栏折叠后不再占位**，聊天区保持居中。

## 修复

- **文件路径出现半截 `..`**：聊天里文件 chip 复制出的路径会带 `/../`（`resolveRelativeToAbsolute` 与 `joinPreviewPath` 都是字符串直拼、没有折叠点段）。现在新增 `normalizeFilePathSegments` 折叠 `.` / `..`，保留盘符、UNC、`~` 根前缀，展示与复制共用同一规范化结果，同一文件的不同写法也只会开一个预览 Tab。
- **置顶或归档让项目跳到最前**：`updateAgentSessionMeta` / `updateConversationMeta` 原来每次写入都无条件刷新 `updatedAt`。现在两个写入口新增 `touchUpdatedAt`（默认 true），置顶、归档相关入口统一传 false，状态变化立刻可见但不改动排序。
- **引用胶囊排版**：新增引用时收齐已有胶囊重排到正文首行，编号顺序 = 行内顺序 = 插入顺序，不再留空段落；胶囊右侧常驻 15px 给移除按钮，悬停才出现，不挤开相邻胶囊。
- **Pi 模型档位**：对齐 GLM-5.3 与 Kimi K3 的官方 `reasoning_effort` 档位和窗口/价格数据。
- **测试与文档**：远端用例跨平台化（FRP 安装按宿主平台生成 zip/tar.gz，token 迁移统一路径键），同步教程与 macOS 设置契约断言。

## 升级提示
