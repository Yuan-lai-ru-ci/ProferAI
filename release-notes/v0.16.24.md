# Profer v0.16.24

## 新增

- **Agent 会话回退（Shadow Git）**：回退对话时可同时恢复文件，支持「预览 → 执行 → 撤销」全链路；按轮次记录受控写入（Write/Edit 与 Pi 受控回调），Bash 改动只报告不猜路径；回退后下一轮会明确告知模型「上一轮已被回退」，不会假装没发生。
- **新的 Agent 执行链默认开启**：桌面、飞书/headless、定时任务、手机端四条入口默认走 `packages/agent-runtime` 新链，系统提示词、动态上下文、`@` 引用与历史回填与旧链对齐；显式设置 `PROFER_RUNTIME_*=0` 可临时回旧链。
- **消息气泡文件改动标记**：工具写入的文件以 chip 挂在消息上，历史回放同样可见（managed 草稿区按既有语义不展示）。
- **预设可绑定渠道与模型**：预设新增渠道选择，绑定渠道时必须同时选择模型；创建、更新、复制、提升全局都会透传渠道绑定。
- **用户画像设备/服务器目录**：画像页可直接查看与编辑设备清单（含类型）与服务器目录。
- **长会话建议新开会话**：达到轮数阈值或上下文占用 80% 时提示交接，当前会话自动生成任务导向的交接文档，新会话带着它从干净上下文继续（设置 → Agent → 长会话，默认关闭）。
- **标签页与侧边栏**：顶栏右键支持「关闭其他 / 关闭右侧」，预览 Tab 可复制源码，当前会话支持拖拽排序与可见数量配置。

## 优化

- **停止收敛**：停止不再等待 provider 清理，终态一定送达；子会话新增 interrupted 状态，停止父会话会立即中断等待中的 `wait_for_delegations`。
- **跨内核模型选择**：会话内核不兼容的渠道仍展示但置灰并说明原因，不再让用户以为模型丢失。
- **迷你地图**：导航轨道固定在会话区域右侧，不随消息列宽漂移。
- **light 模式**：新会话短问候不加载 MCP/Skill、不拼动态上下文，首字更快。

## 修复

- **无人值守入口卡在「等待批准」**：定时任务、飞书、调试通道在 bypassPermissions 下不再挂起，权限端口直接放行且不产生审批请求；Pi 在该模式下不再安装审批回调。
- **回退后「文件改动」面板残留**：回退成功后按删除/还原结果清理面板记录，冲突项保留。
- **删除会话时的停止结果**：适配新的 stopped/already_finished 返回值，避免删除队列误判。
- **跨内核会话投影**：内核与渠道不匹配时不再广播可执行投影；启动期新增内核/transcript 一致性审计（只报告，不自动改写历史数据）。

## 升级提示

- **回退依赖 Shadow Git**：首次使用会在配置目录下建立影子仓库，不写入项目本身；Bash 产生的改动归属为「未确认」，回退时保留文件。
- **新执行链默认开启**：如遇问题可临时设置 `PROFER_RUNTIME_DESKTOP=0`、`PROFER_RUNTIME_HEADLESS=0`、`PROFER_RUNTIME_AUTOMATION=0`、`PROFER_RUNTIME_REMOTE=0` 回旧链，重启应用生效。
- **历史会话审计**：升级后启动会扫描既有会话的内核/transcript 一致性，仅在日志中报告不一致项，不会自动修改。
