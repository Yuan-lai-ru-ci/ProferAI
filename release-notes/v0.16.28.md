# Profer v0.16.28

## 修复

- **修复 0.16.27 启动即崩、窗口不出现**：主进程 CJS bundle 里对纯 ESM 包 `@earendil-works/pi-coding-agent` 的静态导入会被 esbuild 保留成顶层 `require()`，Electron 在加载阶段抛 `ERR_PACKAGE_PATH_NOT_EXPORTED`，应用根本走不到创建窗口。Skill 医生的 frontmatter 结构校验改为运行时 `await import()`，不再污染 bundle 顶层；`frontmatter-invalid` 诊断保留。
- 0.16.27 已从四条更新通道回滚，GitHub Release 置为 prerelease；请直接安装 0.16.28（本机若已下载过 0.16.27，取消待安装即可）。

## 发版门禁

- **构建期拦截纯 ESM 顶层 require**：`verify-build-target` 不再依赖硬编码包名，改为读 esbuild metafile 的 external 列表逐个 `require.resolve()`；`pkg` 与 `pkg/subpath`（如 `@earendil-works/pi-ai/compat`）都会被覆盖，命中 `ERR_PACKAGE_PATH_NOT_EXPORTED` 直接构建失败。
- **打包产物启动冒烟**：打包后真实拉起解包产物（隔离 userData 与配置目录），等主进程探针写出「主窗口已创建」；加载阶段崩溃、bootstrap 抛错、或超时没建出窗口一律中止发版。macOS 本地发版（`dist:mac*`）、Windows 发版链（`release:verify:windows*`）与 OSS CI 都接入了这一步——这是 0.16.27 链路里唯一缺失的门禁。

## 升级提示

- 本版无数据迁移，用户数据与设置不受影响。
- 仍保持 macOS Apple Silicon 构建范围；macOS 本地验收包为 ad-hoc、无公证。
