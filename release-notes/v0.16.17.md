# Profer v0.16.17

## 新增

- **任务来源可追溯**：每条消息记录真实作者与来源（用户输入、Agent 派工、定时任务、外部请求）。任务交接与定时触发显示独立的来源卡，可直接定位到来源会话或定时任务；来源已删除时只提示状态，不显示内部编号。
- **运行账本**：每次执行都有独立的运行记录（排队 / 运行中 / 等待审批 / 完成 / 失败 / 停止）。重启后对账上次中断的运行并说明原因，排队中的任务保留但不自动重放未知副作用。
- **派工三种位置**：`delegate_agent(s)` 支持 current（在当前会话展开）、child（子会话）、independent（独立执行，不随父会话停止），并可区分「子任务」与「独立任务」；旧调用行为不变。
- **定时任务绑定目标会话**：定时任务可指定固定执行会话，忙碌时排队而不是另起会话；目标失效、模型或渠道不匹配时保留原因，不静默换会话。表单可直接选目标会话，列表展示排队、受阻、执行中与中断的触发。

## 优化

- **Pi 上下文预算**：工具结果与图片改为成批整理，超限时一次腾出一半空间，不再每来一组工具结果就重写历史；已缓存的请求前缀保持稳定，长会话缓存命中率明显提高。
- **启动更快**：文件预览、浏览器、白板、插件页、全屏视图与欢迎页改为按需加载，图标包与表情选择器首次使用时才加载。新增启动预算门禁：入口同步资源超过 4MB / 1.28MB gzip 时构建直接失败（当前 3.6MB / 1.09MB）。
- **更新下载**：检查更新不再等整包下载完才返回；下载失败会按可达性换源重试，换源期间界面不会被拽回「检查中」。

## 修复

- **退出后更新装不上**：退出时的远控清理改为 3 秒预算，超时也继续退出；点「重启安装」后 12 秒仍未退出则强制结束。此前旧进程卡住会让 macOS 与 Windows 的安装器一直等下去。
- **登出丢自配渠道**：登出只清理官方代管渠道，用户自配的 API 渠道原样保留；旧版本留下的加密备份仍会在下次登录时合并恢复。
- **子会话置顶**：委派与探索子会话不允许单独置顶，位置跟随母会话；命令面板与移动端同步拦断。
- **发布差分**：发布前校验上一版本 blockmap 仍可访问，缺失时阻断或告警，避免存量用户下次更新静默退化成 220MB+ 全量下载；顺带修复 Windows 发布主机上该门禁的 curl 引号与空设备问题。

## 升级提示

- 自本版起 macOS 与 Windows 可以任意顺序发布：先发的一方创建 Release，后发的一方只补自己的资产。
