# v0.17.1

## 独立 Core 与跨设备连接

- 本机 Core 默认运行，桌面与独立 Headless 共用执行内核；保留显式 legacy 启动入口。
- 支持一次性邀请、持久 TLS 身份、局域网发现和离线目标保留，分别维护各 Core 的会话与导航。
- Core 与旧桌面共用执行锁，升级后接续已有会话与工作区；修复预览命名空间和共享快照宿主绑定。
- 独立 Core 管理商业账号、续期与官方模型目录，补充账号恢复重试。

## 多窗口

- 支持会话拆窗的确认交接与失败恢复，窗口分别保留 Core 连接、会话与草稿。
- 主页面关闭后由剩余完整窗口自动接任，最后一个窗口沿用原隐藏行为。
- 接任时刷新共享导航保存基线，保留其他 Core 的最新历史。

## 界面与模型

- 收敛设置导航、Tab、共享滚动和空状态，增加 Skill 路由卡缺失提醒。
- 更新模型目录和推理参数适配，完善上下文用量展示。

## 安装与更新

- 商业桌面版提供 macOS arm64、Windows x64 和 Linux x64 安装包，另提供独立 Linux x64 Headless Core。
- 正式版恢复正式通道的更新检查、下载与安装；各平台签名和验收状态见随包清单。
